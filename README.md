# feed-page

一个简洁的个人动态聚合页，用于集中展示由 Muse 自动同步的资讯、工作动态与待办想法。

页面围绕压力蒸汽灭菌器、低温灭菌、医疗器械、行业招采、标准法规、厂家动态等主题组织内容，将每条动态按日期、分类和重要信息卡片化呈现，方便快速浏览和追踪。

## 功能

- 按日期展示动态内容
- 支持按标题或正文关键词搜索
- 支持按分类筛选动态
- 兼容浅色与深色系统主题
- 卡片化展示来源链接、统计信息和跟进理由
- 纯静态页面，无需后端或构建工具

## 使用

直接打开 `index.html` 即可运行，也可以使用任意静态文件服务器托管。例如：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 数据维护

动态数据目前内嵌在 `index.html` 的 `POSTS` 常量中。页面底部会标注数据同步来源和最近同步时间；如需更新内容，可由同步程序重新生成该文件。

## 技术栈

- HTML
- CSS
- 原生 JavaScript

无需安装依赖，也无需编译构建。
